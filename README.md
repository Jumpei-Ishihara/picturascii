# PICTURASCII

Turn the subject of a picture, video, or camera feed into living ASCII.
Everything runs in the browser — no uploads, no server.

**Live:** https://jumpei-ishihara.github.io/picturascii/

> Status: **W2** — v0.2 adds PERSON (person segmentation). The rendering core is ported from the
> desktop app (AI Object Detection Visualizer, Python/OpenCV) to JavaScript +
> WebGL2 and verified against it.

## Features (v0.1)

- **Sources:** built-in animated sample, image / video files (open or drop), camera
- **Detect:** FULL, AUTO (dark background → brightness, bright → color), PERSON (person segmentation, with a DETAIL mode that keeps hands and fingers), CHROMA with an eyedropper; invert. The camera starts in PERSON.
- **Characters:** digits, hex, binary, ASCII ramp, symbols, or your own text; pick by brightness or at random
- **Look:** hue or per-cell source color, gamma, color range, saturation, background color, 3-scale glow, pulse, size animation, NORMAL / ADD / SCREEN blending
- **Output:** JPEG snapshot, WebM recording (MP4 where the browser only records MP4), output size up to the source resolution
- Seven presets; settings are remembered in this browser

## How it works

| Stage | Where | Port of (desktop `visualizer.py`) |
|---|---|---|
| Subject mask — FULL / AUTO / CHROMA | CPU (`src/detect.js`), at ≤480 px wide for live use | `detect_silhouette`, `_mask_chroma_bg`, `_postprocess_mask` |
| Subject mask — PERSON | MediaPipe selfie segmenter (`src/person.js`, bundled in `vendor/`, loaded only when selected) + CPU post-processing | `_mask_person_mediapipe` |
| Character grid, density mapping, deterministic animation | CPU (`src/grid.js`) | `draw_silhouette_grid` |
| 3-scale glow, background, opacity, blend modes | GPU (`src/gl.js`) | `_multi_glow`, `process_frame`, `_composite` |

Glyphs are the desktop app's Hershey Duplex tiles, exported once per character
(`assets/glyphs/`), so the web version draws the same letterforms.
Random values (splitmix64 hashes, Python's MT19937) are reproduced bit-for-bit.

## Development

Serve the folder with any static server. `tools/serve.py` disables caching for development:

```bash
python3 tools/serve.py 8765
```

Then open `http://127.0.0.1:8765/`. There is no build step.

### Tests

```bash
node test/unit.mjs
```

Checks hashes, Python `random`, and OpenCV HSV conversion against values
exported from the desktop app (`test/unit_expected.json`).

Open `http://127.0.0.1:8765/test/compare.html` to render every case in
`test/cases.json` and compare it with the desktop output in `test/reference/`.
A case passes at PSNR ≥ 30 dB with fewer than 1% of pixels off by more than 32.
PERSON cases are judged by mask IoU ≥ 0.9 instead, because the desktop app uses the
legacy MediaPipe Solutions runtime and the web uses MediaPipe Tasks.

### Regenerating assets (needs the desktop repo and its Python env)

```bash
python tools/gen_atlas.py        --desktop-repo <path>   # assets/glyphs*
python tools/gen_test_images.py                           # test/fixtures (synthetic)
python tools/gen_reference.py    --desktop-repo <path>   # test/reference
python tools/gen_unit_expected.py --desktop-repo <path>  # test/unit_expected.json
```
